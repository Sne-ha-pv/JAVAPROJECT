\# Vehicle Rental System - User Manual



\## 1. Introduction



This user manual explains how to run and use the Vehicle Rental System.



The application is a menu-driven Java console program.



\## 2. System Requirements



\- Java JDK 21 or later

\- Windows/Linux/macOS

\- Command Prompt, PowerShell, or Terminal



\## 3. Running the Program



Open the terminal inside the `src` folder.



Compile the program:



```text

javac \*.java
