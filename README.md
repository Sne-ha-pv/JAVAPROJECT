\# Vehicle Rental System



\## Project Description



The Vehicle Rental System is a Java-based console application developed using Object-Oriented Programming (OOP) concepts.



The system manages vehicles, customers, bookings, rental costs, security deposits, late-return penalties, and vehicle availability.



\## Features



\- Add new vehicles

\- Display vehicles

\- Search vehicles by type

\- Search vehicles by brand

\- Update vehicle details

\- Remove vehicles

\- Add customers

\- Book vehicles

\- Calculate rental cost based on rental duration

\- Track real-time vehicle availability

\- Process vehicle returns

\- Calculate late-return penalties

\- Calculate security deposit refunds

\- Maintain customer rental history



\## Technologies Used



\- Java

\- Object-Oriented Programming

\- Java Interface

\- ArrayList

\- LocalDate

\- Scanner



\## OOP Concepts Used



\### 1. Encapsulation



Private data members are used in the classes with public getter and setter methods.



\### 2. Interface



The `Rentable` interface defines methods for rental cost calculation and availability management.



\### 3. Classes



The project contains the following main classes:



\- `Vehicle`

\- `Customer`

\- `Rental`

\- `RentalAdmin`

\- `Main`



\### 4. ArrayList



`ArrayList` is used to store vehicles, customers, and rental records.
